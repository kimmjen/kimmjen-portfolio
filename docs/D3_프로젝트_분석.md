# D3 프로젝트 - 분산 에너지 자원 데이터 분석 및 시각화 플랫폼

## 프로젝트 개요

D1에서 구축한 CBL 데이터를 기반으로, **분산 에너지 자원의 시계열 데이터를 분석·시각화하여 통계 보고서를 생성·공유하는 서비스**.
다양한 데이터 소스(CSV, EIP VPP, AWS S3)를 연동하여 데이터셋을 생성하고, 차트 기반 시각화 및 대시보드를 통해 인사이트를 제공합니다.

- **기간**: 2022.08 ~ 2023.09
- **역할**: 풀스택 개발 (기획, 프론트엔드 UI, 백엔드 API, DB 구축, CI/CD, 배포)

## 핵심 기능

### 1. 데이터 소스 통합 및 데이터셋 관리

다양한 소스에서 데이터를 수집하여 통합 데이터셋으로 관리.

**지원 데이터 소스:**
| 소스 | 설명 |
|------|------|
| **CSV 업로드** | 파일 직접 업로드, 스키마 자동 감지 |
| **EIP (Energy IP)** | VPP 플랫폼 연동 - 참여자, 리소스, 리포트, 이벤트 데이터 |
| **AWS S3** | 클라우드 저장소 연동, 암호화된 자격증명 |

**데이터셋 기능:**
- 필드 매핑 및 타입 지정 (timestamp, integer, float)
- 타임존 인식 처리
- 생성 전 데이터 미리보기
- 사용자 필터 및 조인 기반 메타데이터 보강
- 버전 관리 및 스케줄링

### 2. 시각화 및 차트 분석

KDB+ 시계열 DB에서 데이터를 조회하여 Highcharts로 시각화.

**차트 기능:**
- 다중 시리즈 데이터 시각화
- 차트 유형: 라인, 바, 영역, 산점도 등
- 시계열 집계 분석
- 사용자 정의 시리즈 선택 및 필터링
- 차트 메타데이터 영속 저장

### 3. 대시보드 및 리포팅

드래그앤드롭 기반의 대시보드 구성 및 보고서 공유.

**대시보드 기능:**
- 대시보드 그룹 (관련 대시보드 모음)
- GridLayout 기반 드래그앤드롭 배치
- 다중 차트 배치
- 실시간 데이터 새로고침
- 인쇄/내보내기
- 워크스페이스 기반 조직 관리

### 4. 자동 데이터 수집 (스케줄링)

APScheduler 기반 1분 주기 자동 데이터 동기화.

**프로세스:**
1. APScheduler가 1분마다 트리거
2. 스케줄된 데이터셋 인덱싱
3. 각 스케줄별 실행 시점 확인
4. Data Collector가 소스(EIP API 등)에서 데이터 수집
5. KDB+로 변환 및 upsert
6. 동기화 타임스탬프 업데이트
7. 완료 시 이메일 알림 발송 (AWS SES)

### 5. 시계열 데이터 분석

- **미터 데이터**: 소비량/수요량 측정값
- **이벤트 분석**: 수요반응 이벤트, 부하 전환
- **CBL 계산**: D1에서 구축한 기준 부하 데이터 활용
- **통계**: 집계, 비교, 예측

## 프론트엔드 구조

### 3개의 프론트엔드가 존재하는 이유

| 폴더 | Vue 버전 | 빌드 도구 | 용도 |
|-------|----------|-----------|------|
| `front/` | Vue 2.7 | Webpack 5 | **메인 프로덕션 UI** - 데이터 분석/시각화/대시보드 |
| `front-quasar/` | Vue 3.3 | Vite | **실험적 프로토타입** - Quasar 프레임워크 테스트 |
| `front-vite/` | Vue 3.2 | Vite | **사용자 가이드 문서** - `/docs` 경로로 배포 |

**빌드 전략:**
- `build.sh`가 `front`와 `front-vite` 두 개를 동시 빌드
- `front` → 메인 UI (루트 `/`)
- `front-vite` → 문서 UI (`/docs`)
- 둘 다 Flask의 static 폴더로 배포, SPA 라우팅 폴백

### 메인 UI 주요 컴포넌트

```
front/src/
├── components/
│   ├── Analysis/         # 데이터 분석 컴포넌트
│   ├── Layout/           # 레이아웃 (네비게이션, 사이드바)
│   ├── Common/           # 공통 UI 컴포넌트
│   ├── login/            # 인증 UI
│   ├── settings/         # 사용자 설정
│   └── resources/        # 리소스 관리
├── router/               # Vue Router
├── store/                # Vuex 상태관리
├── api/                  # API 클라이언트
└── styles/               # SCSS 스타일
```

| dashboard | 개별 대시보드 |
| dashboard_visual_rel | 대시보드-시각화 연결 |
| user_data_source | 사용자 데이터 소스 설정 |
| dataset_schedule | 자동 수집 스케줄 |
| dataset_schedule_job | 수집 작업 이력 |
| d3_history | 전체 작업 감사 로그 |

### KDB+ (시계열 데이터)

| 인스턴스 | 포트 | 용도 |
|----------|------|------|
| Ticker/RDB (Source) | 6010/6011 | 실시간 미터 데이터 |
| HDB (Historical) | 6013 | 장기 이력 데이터 (날짜별 파티션) |
| ADB (Analysis) | 6017 | 분석 결과 테이블, 캐시 |

## 데이터 흐름

### 데이터셋 생성 흐름
```
사용자 → CSV 업로드 / EIP 소스 선택 / S3 연결
  → 데이터 미리보기 및 스키마 검증
  → 타입 매핑 (timestamp, int, float)
  → KDB+ 테이블 생성 (bi_v1.get_dataset)
  → PostgreSQL에 메타데이터 저장
  → 데이터셋 사용 가능
```

### 시각화 흐름
```
사용자 → 시각화 생성
  → 데이터셋 연결
  → 차트 생성 (필드 매핑)
  → KDB+에서 데이터 쿼리
  → Highcharts로 렌더링
```

### 대시보드 흐름
```
사용자 → 대시보드 그룹 생성
  → 대시보드 추가
  → 시각화 배치 (GridLayout 드래그앤드롭)
  → 새로고침 주기 설정
  → 공유/발행
```

## 배포 환경

```yaml
# docker-compose.yml
services:
  D3:
    image: eipgridinc/d3:v1.0.1
    ports: "5500:5000"
    volumes:
      - ./config:/www/config
      - ./logs:/www/logs
      - ./storage:/www/storage
    environment:
      - ENV=dev
      - TZ=Asia/Seoul
```

**CI/CD (GitHub Actions):**
1. Push → d3-nightly 브랜치 트리거
2. Docker 이미지 빌드
3. Docker Hub 로그인 및 푸시 (`eipgridinc/d3:d3-nightly`)
4. 셀프 호스트 러너에서 Docker 실행
5. AWS Elastic Beanstalk 배포 (`d3-dev` 환경)
6. Google Chat 알림 발송

**배포 URL:**
- DEV: `https://d3-dev.eipgrid.com`
- DEV(B): `https://d3-dev-env.eipgrid.com`
