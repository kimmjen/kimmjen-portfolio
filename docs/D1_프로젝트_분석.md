# D1 프로젝트 - 수요반응 CBL 계산 및 ESS 스케줄링 플랫폼

## 프로젝트 개요

수요반응(Demand Response) 프로그램 평가를 위한 **고객 기준 부하(CBL) 계산 시스템** 및 **ESS(에너지 저장 시스템) 스케줄링 플랫폼**.
전력거래소 기준서 기반으로 한국, 일본, 말레이시아 등 다국가 전력시장 규정에 따른 CBL 알고리즘을 구현하고, 배터리 충·방전 최적화 스케줄링을 제공합니다.

- **기간**: 2021.12 ~ 2024.07 (아이온커뮤니케이션즈 → 이아이피그리드 연속)
- **역할**: 풀스택 개발 (백엔드 API, 프론트엔드 UI, CI/CD, 서버 배포)

## 핵심 비즈니스 로직

### 1. CBL (Customer Baseline Load) 계산

고객의 기준 부하를 산출하여 수요반응 참여 성과를 평가하는 핵심 알고리즘.

**CBL 유형별 파라미터:**

| 유형 | 조회 기간 | 참조일수 | 최대일수 | 적용 국가 |
|------|-----------|----------|----------|-----------|
| MAX_4_5 | 10일 | 5일 | 4일 | 한국 |
| MID_4_6 | 12일 | 6일 | 4일 | 한국 |
| MID_6_10 | 20일 | 10일 | 6일 | 한국 |
| MID_8_10 | 20일 | 10일 | 8일 | 한국 |
| JP_STANDARD_BL | 30일 | 5일 | 4일 | 일본 |
| JP_EQUAL_30_DAY | 30일 | 3일 | 3일 | 일본 |
| JP_PRE_MEASUREMENT | 2일 | 2일 | 1일 | 일본 |

**알고리즘 프로세스:**
1. KDB+에서 시계열 미터 데이터 추출
2. 휴일/주말 필터링 (국가별 공휴일 라이브러리 활용)
3. 목표 인터벌로 리샘플링 (15분/30분/60분)
4. 참조일 선정:
   - Level 1: 시간당 합계 평균의 75% 미만인 비정상 운영일 제외
   - Level 2: 75~125% 범위의 생산 조정일 필터링
   - 최종: 가장 최근 N일의 참조일 선정
5. SAA(특별 조정 알고리즘) 적용 (선택)
6. CBL 커브 생성 및 출력

**다국가 지원:**
- `cbl_kor_2020.py` - 한국 전력거래소 기준
- `cbl_jp_2020.py` - 일본 전력시장 기준
- `cbl_malay_2022.py` - 말레이시아 기준

### 2. ESS (Energy Storage System) 스케줄링

배터리 충·방전 최적 스케줄을 생성하여 피크 부하를 관리하는 알고리즘.

**스케줄러 유형:**

| 스케줄러 | 방식 | 설명 |
|----------|------|------|
| DayAhead V1 | 규칙 기반 | 초기에 빠르게 충전, 피크 시간대 방전 |
| Runtime V1 | 규칙 기반 실시간 | 현재 시점부터 잔여 시간 분석 |
| DayAhead Optimized V1 | 최적화 (LP) | 전기료 최소화 목적함수, PuLP/Pyomo 활용 |
| Adaptive Runtime | 적응형 실시간 | 5분 주기 모니터링, 10분 평균 기반 예측 |

**최적화 제약 조건:**
- 피크 시간대: 부하 ≤ 피크 제한값
- SOC (충전 상태): 최소/최대 범위 유지
- PCS (전력 변환): 출력 제한 준수
- 배터리 사이클 효율 반영 (기본 1.2)

### 3. RRMSE (Root Mean Root Squared Error) 검증

CBL 계산 결과의 통계적 정확도를 검증하는 분석 도구.
- CSV 기반 미터 데이터 업로드
- CBL 유형별 비교 분석
- 통계 보고서 생성

### 4. Amadeus - 수요반응 시뮬레이터

참여자 데이터를 기반으로 Balancing Group을 생성하고 수요반응을 분석하는 고급 시스템.

**클러스터링 알고리즘:**
- K-Means 클러스터링
- DBSCAN 클러스터링
- Divide-and-Conquer 기법
- Balance Group 자동 생성

**스케줄링:**
- 개별 고객 스케줄링
- 그룹 기반 최적화 스케줄링

## 데이터베이스 모델

### PostgreSQL (RDB)
- **users**: 사용자 계정 (JWT 인증, 역할 관리)
- **cbl_tests**: CBL 테스트 케이스 (JSON 형태 저장)
- **alerts**: 알림/알람
- **recalculate_his**: CBL 재계산 이력 추적
- **user_vpp_rel**: 사용자-VPP 연결 관계

### KDB+ (시계열 DB)
- 실시간 미터 데이터 (Ticker/RDB)
- CBL 계산용 사용자/VPP/리소스 데이터
- 분석 결과 테이블 (Analysis DB)
- 3개 KDB 인스턴스: src(소스), analysis(분석), d1(전용)
