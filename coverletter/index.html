자 기 소 개 서

지원자: 김제민 (KIM JE MIN)

01.직무 경험 및 역량: 대용량 데이터 파이프라인부터 사용자 인터페이스까지

대용량 시계열 데이터를 수집하고 정제하여 직관적인 화면으로 전달하는 풀스택 개발자입니다. 약 3년간 에너지(VPP) 플랫폼 현장에서 KDB+ 시계열 데이터베이스, PostgreSQL, Flask/FastAPI 백엔드, Vue.js 프론트엔드를 아우르는 전 과정을 직접 설계하고 운영했습니다.

아이온커뮤니케이션즈 입사 후 첫 과제로 전력거래소 기준서에 맞춘 고객 기준 부하(CBL) 계산 시스템(D1)을 개발했습니다. 한국과 일본 전력시장 규정에 맞춘 7가지 CBL 알고리즘(MAX_4_5, MID_4_6, JP_STANDARD_BL 등)을 구현했고, 15분·30분·60분 주기의 시계열 데이터를 KDB+ Q 언어로 조회·가공하여 수요반응 성과를 정량적으로 산출했습니다. 이 시스템은 이후 이아이피그리드로 이관되어 2년간 운영과 기능 개선을 맡으며 서비스 안정성을 지켜냈습니다.

이아이피그리드에서는 D1 운영 경험을 살려 분산 에너지 자원의 시계열 데이터를 분석·시각화하는 D3 플랫폼 개발을 기획 단계부터 함께했습니다. CSV, EIP VPP API, AWS S3 등 여러 소스에서 1분 주기로 데이터를 모으는 수집 파이프라인을 구축하고, Highcharts 다중 시리즈 차트와 드래그앤드롭 대시보드를 구성하여 실무자가 통계 보고서를 직접 조합해 볼 수 있도록 만들었습니다. PostgreSQL 스키마 설계부터 30여 개 REST API 엔드포인트 개발, Vue.js 화면 전체 구현, Docker 및 GitHub Actions CI/CD 파이프라인 구축까지 전 과정을 도맡아 완성했습니다.

이후 Arkn(전기차 충전소 모니터링), Amadeus(Balancing Group 분석), EnergyHub(VPP 가상 리소스 생성) 프로젝트에서도 Vue.js 대시보드와 FastAPI 백엔드를 개발하며, 이동형 ESS 배터리의 충·방전량 실시간 관제, 전력 지령 이행률 추적 화면, 통합 알림 기능 등 에너지 도메인에 특화된 실무 요구사항을 빠짐없이 구현했습니다.

02.문제 해결 사례: 현장의 비효율을 시스템으로 개선한 경험

업무 현장에서 발생하는 수작업 병목이나 성능 지연을 발견하면, 기술로 원인을 짚어내고 자동화 시스템으로 전환하는 데 집중합니다.

첫째, 에코아이티(ECHOIT)에서 '라벨링 품질 검수 플랫폼'을 자체 구축했습니다. '국회 AI를 위한 데이터 구축' 사업 초기에는 3명의 검수자가 수작업으로 데이터를 대조하다 보니 기준이 제각각이고 단순 실수도 잦았습니다. 이를 바로잡고자 React, TypeScript, FastAPI, Supabase를 엮어 검수 웹 플랫폼(labeling-qc.com)을 직접 개발했습니다. 중복 데이터 필터링, JSON 포맷 검사, 필드 간 논리 모순 확인 등 10가지 자동 검증 룰을 적용하고 대용량 ZIP 일괄 처리와 실시간 품질 통계 화면을 붙였습니다. 그 결과 검수자들은 단순 오탈자 확인 대신 고난도 법률·정책 문맥 검증에만 집중할 수 있었고, Docker와 AWS Lightsail로 배포 환경까지 완성해 프로젝트 마감까지 안정적으로 운영했습니다.

둘째, D1 프로젝트의 동기식 API를 FastAPI 비동기 구조로 전환했습니다. 기존 Flask 서버는 KDB+ 시계열 쿼리나 PuLP/Pyomo 기반 ESS 스케줄링 연산이 길어지면 서버 전체가 멈추는 블로킹 현상이 발생했습니다. 특히 여러 VPP의 CBL 계산 요청이 동시에 몰릴 때 지연이 심해졌습니다. 이를 개선하기 위해 Uvicorn ASGI 서버 기반의 FastAPI로 마이그레이션하고, Gevent 기반 8개 분산 태스크 워커를 배치해 무거운 계산을 요청 처리 흐름에서 분리했습니다. 오래 걸리는 연산이 서버 전체를 막지 않는 구조로 정리한 것입니다.

셋째, D1·D3 배포 과정을 GitHub Actions로 자동화했습니다. 수동 접속 배포 방식을 걷어내고 브랜치 Push 시 Docker 이미지 빌드, 레지스트리 전송, AWS Elastic Beanstalk 자동 갱신, 배포 완료 메신저 알림까지 이어지는 파이프라인을 구축했습니다. 개발·스테이징·운영 환경별 설정을 철저히 분리하여 고객사별 독립 배포를 실수 없이 진행할 수 있게 했습니다.

03.기술적 역량: 전력 데이터와 웹 엔지니어링의 결합

백엔드와 데이터 영역에서는 FastAPI와 Flask를 활용해 RESTful API를 설계하고, PostgreSQL 스키마를 직접 설계해 모델링합니다. KDB+ Q 언어로 초·분 단위 대용량 시계열 전력 데이터를 집계한 경험이 있으며, Redis 캐시와 Pub/Sub을 활용해 실시간 상태 동기화 환경을 만들었습니다. 선형 프로그래밍(PuLP/Pyomo)으로 ESS 충·방전 스케줄링 최적화 알고리즘을 코드로 풀고, Pandas와 Scikit-learn으로 고객 군집화(K-Means, DBSCAN)를 진행했습니다.

프론트엔드 영역에서는 Vue.js(2/3)와 Highcharts로 에너지 관제 화면과 시계열 차트를 다수 제작했습니다. 최근에는 React, Next.js, TypeScript를 주력으로 다루며 개인 프로젝트 'Refine'을 통해 Next.js 16과 React 19, Supabase, Gemini AI를 결합한 PWA 서비스를 구축해 46개 Vitest 단위 테스트로 품질을 검증하며 운영 중입니다.

인프라 및 운영에서는 Docker 컨테이너 오케스트레이션과 GitHub Actions CI/CD를 기본으로 삼고, AWS(EC2, Elastic Beanstalk, RDS, S3, Lightsail) 환경에서 환경 분리(dev/stage/prod)와 무중단 배포를 관리해 왔습니다.

04.성장 과정 및 가치관: 빠른 습득력과 비즈니스 중심의 실행력

경영학을 전공하며 비즈니스 흐름과 사용자 경험의 중요성을 익혔고, 데이터의 가치에 매료되어 빅데이터 분석 과정과 기업 연계 개발자 교육을 거치며 소프트웨어 엔지니어로 안착했습니다. 입사 초기부터 전력거래소 기준서라는 낯설고 까다로운 도메인 규칙을 빠르게 해석하여 Python 코드로 옮겨 담았습니다.

경영학 전공 배경은 코드를 작성할 때 '이 기능이 실제 현업의 어떤 비용을 아끼고 누구의 수고를 덜어주는가'를 먼저 따져보는 시야를 갖추게 해 주었습니다. D3 프로젝트에서 요구사항 정의와 스프린트 설계를 주도하고, 에코아이티에서 검수 자동화 도구를 먼저 만들어 제안했던 것도 이러한 고민에서 출발했습니다.

회사 업무에서는 Vue.js, FastAPI, KDB+ 중심의 엔터프라이즈 환경을 다루고, 개인 프로젝트에서는 Next.js와 TypeScript 기반의 최신 생태계를 다루며 기술적 유연성을 유지하고 있습니다. 새로운 도구라도 문제 해결에 필요하다면 주저 없이 익혀 프로덕션 수준의 결과물로 만들어냅니다.

05.지원 동기 및 포부: 안정성과 사용성을 모두 잡는 엔지니어

복잡한 알고리즘과 대규모 인프라도 결국 신뢰할 수 있는 데이터 파이프라인과 직관적인 화면이 갖춰져야 제 가치를 발휘합니다. 3년간 에너지 플랫폼 현장에서 시계열 데이터 쿼리 최적화부터 사용자 대시보드까지 전 계층을 다루며 얻은 확신입니다.

입사 후 PostgreSQL/KDB+ 기반 데이터베이스 설계, FastAPI/Flask 고성능 API 구축, React/Vue.js 데이터 시각화 화면 구현, Docker 기반 배포 자동화 역량을 아낌없이 쏟겠습니다. 다양한 전력 규정을 코드로 옮기고 현장의 비효율을 자동화로 걷어낸 경험을 살려, 어떤 시스템이든 기민하게 원인을 찾고 안정적으로 풀어내는 신뢰받는 개발자가 되겠습니다.
