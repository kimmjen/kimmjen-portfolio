02. 정성평가 서술형 작성본

공고 문항: 본인의 직무역량 향상에 영향을 준 사항을 1개 이상 선택하고 그 이유, 과정, 결과 등을 기술

공백 포함: 1566자 / 1500자 기준공백 제외: 1207자

[데이터의 정합성을 지키기 위해 직접 검수 웹 플랫폼을 구축한 경험]

주식회사 에코아이티에서 국회 AI를 위한 데이터 구축 사업에 참여했을 때의 일입니다. 당시 3명의 검수자가 수작업으로 원문과 가공 데이터를 대조하다 보니 작업자마다 판단 기준이 달라지고, 단순한 JSON 포맷 오류나 필수 메타데이터 누락 같은 실수가 계속 생겼습니다. 사람이 눈으로 확인하는 방식만으로는 데이터의 무결성을 보장하기 어렵다는 한계를 느꼈고, 반복되는 검증 작업을 시스템으로 자동화해야겠다고 판단했습니다.

이를 위해 React, TypeScript, FastAPI, Supabase, Docker를 활용해 라벨링 품질 검수 플랫폼을 직접 개발했습니다. 10가지 검증 규칙을 설계해 JSON 스키마 유효성, 필드 간 논리적 모순, 필수 메타데이터 누락 여부를 시스템이 먼저 걸러내도록 엔진을 구현했습니다. 또한 수백 메가바이트 규모의 대용량 ZIP 압축 파일을 브라우저에서 바로 풀어 구조를 분석하고, 검수자가 오류 지점을 즉시 확인해 수정할 수 있는 인터페이스와 실시간 품질 통계 대시보드를 구축했습니다.

자동 검증 플랫폼을 도입한 결과, 단순 포맷 오류는 시스템이 100% 잡아내어 검수자 간 기준 편차를 완전히 없앴습니다. 덕분에 작업자들은 단순 오탈자 확인 대신 고난도 문맥 검증과 정책 적합성 판단에만 집중할 수 있었고, 프로젝트 마감까지 데이터 오류 없이 납품을 마쳤습니다. 이 경험을 통해 데이터의 수집부터 검증, 정제에 이르는 전 과정에서 시스템 차원의 무결성 검증 체계를 설계하는 개발 역량을 체득했습니다.

[대용량 시계열 연산 병목을 비동기 분산 아키텍처로 개선한 경험]

주식회사 이아이피그리드에서 VPP 에너지 플랫폼의 고객 기준 부하(CBL) 계산 시스템을 운영할 때도 성능 병목 문제를 해결한 경험이 있습니다. 고객사들의 수요관리 데이터와 ESS 스케줄링 최적화 연산이 특정 시간대에 집중되면, 기존 동기식 Flask 서버가 일시적으로 멈추며 전체 API 응답이 밀리는 현상이 발생했습니다.

문제를 해결하기 위해 서버를 Uvicorn ASGI 기반의 FastAPI 비동기 구조로 전환했습니다. 부하가 큰 복합 연산 로직은 요청 처리 스레드에서 분리하고, Gevent 기반의 8개 분산 태스크 워커로 비동기 큐잉 처리하도록 구조를 바꿨습니다. 또한 KDB+ 시계열 데이터베이스 쿼리를 손보아 15분·30분 주기 데이터의 조회 지연을 줄이고, Docker와 GitHub Actions를 통해 무중단 배포 파이프라인을 구축했습니다.

그 결과 피크 시간대에도 서버 멈춤 없이 안정적인 가용성을 확보할 수 있었습니다. 시스템 병목의 원인을 정확히 짚어내고 비동기 분산 아키텍처로 대용량 데이터 흐름을 최적화하는 실무 감각을 확립한 계기였습니다.

[입사 후 각오]

디지털 안심국가를 완성하는 한국인터넷진흥원의 업무 역시 대규모 데이터의 신뢰성과 24시간 중단 없는 시스템 안정성이 핵심이라고 생각합니다. 현장에서 마주친 데이터 무결성 문제와 성능 병목을 직접 코드로 해결해 낸 경험을 바탕으로, KISA의 기술 환경에서도 데이터 오류와 시스템 장애를 꼼꼼하게 막아내는 개발자가 되겠습니다.
