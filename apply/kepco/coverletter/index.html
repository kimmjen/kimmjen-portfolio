홈입사지원서경력기술서

Korea Electric Power Corporation · ICT

자 기 소 개 서

지원자: 김제민 (KIM JE MIN)

01.지원 동기 및 직무 비전 — 전력망 지능화와 데이터 기반 신뢰성 확보

저는 아이온커뮤니케이션즈와 이아이피그리드에서 약 3년간 민간 VPP(가상발전소) 플랫폼과 수요반응(DR) 고객기준부하(CBL) 계산 시스템을 개발·운영해 왔으며, 현재 한국에너지공과대학교(KENTECH) AGM Center에서 차세대 전력망 운영 소프트웨어(KPG)의 Python 로직 고도화 및 웹 플랫폼 운영을 담당하고 있습니다.

탄소중립과 신재생에너지 분산 전원의 급증으로 인해 대한민국 전력 계통은 사상 유례없는 복잡성과 변동성에 직면해 있습니다. 이러한 환경에서 한국전력공사(KEPCO)의 ICT 시스템은 단순한 인프라 관리를 넘어, 전력망의 안정성과 경제성을 실시간으로 뒷받침하는 핵심 두뇌 역할을 수행해야 합니다.

민간 VPP 시장과 연구소 전력망 소프트웨어를 두루 거치며 축적한 전력 도메인 지식과 대용량 시계열 데이터 파이프라인 구축 역량을 바탕으로, KEPCO의 차세대 그리드 ICT 시스템 구축과 지능형 전력 데이터 운영에 즉각적으로 기여하고자 지원하였습니다.

02.직무 전문성 — 대용량 전력 시계열 데이터 처리 및 최적화 엔지니어링

전력거래소 기준서에 규정된 CBL 알고리즘 7종을 Python으로 직접 구현하고, 초·분 단위로 수집되는 대량의 스마트미터 전력 데이터를 KDB+ 시계열 데이터베이스를 통해 효율적으로 쿼리·정제하는 시스템을 설계했습니다.

또한 ESS(에너지저장장치)의 피크 부하 감축 및 충·방전 스케줄링을 위해 선형 프로그래밍(PuLP/Pyomo) 최적화 모델을 코드로 구현하여 경제적인 전력 운용 알고리즘을 개발했습니다.

KENTECH 연구소에서는 전력망 해석 애플리케이션인 KPG Run/View의 핵심 Python 로직을 분석하고 성능 병목을 개선하며 계통 해석 소프트웨어의 실무적인 동작 메커니즘을 체득했습니다. 이러한 경험은 KEPCO가 관리하는 방대한 계통 데이터(SCADA/EMS, AMI)의 실시간 모니터링과 분석 파이프라인 고도화에 강력한 강점으로 작용할 것입니다.

03.문제 해결 역량 — 아키텍처 전환을 통한 동시성 병목 극복

D1 프로젝트 운영 당시, 기존 Flask 기반의 동기식 API 구조에서 다수 사업자의 동시 다발적인 대용량 CBL 계산 요청이 발생할 때 서버 응답 지연과 병목 현상이 발생했습니다. 이를 해결하기 위해 Uvicorn ASGI 기반의 비동기 프레임워크인 FastAPI로 시스템을 선제적으로 마이그레이션했습니다.

SQLAlchemy 2.0 비동기 세션을 구축하고, Gevent 기반 분산 작업 워커(8개 태스크)를 설계하여 I/O 블로킹을 해소했습니다. 그 결과 동시 대량 요청 상황에서도 서버 지연을 대폭 감축하고 계산 처리량을 획기적으로 개선했습니다.

레거시 코드의 문제점을 주도적으로 진단하고 최신 아키텍처로 안정적인 전환을 이끌어낸 이 경험은 KEPCO의 대규모 ICT 시스템을 보다 신뢰성 높고 탄력적으로 유지하는 데 밑거름이 될 것입니다.

04.협업과 소통 — 도메인 전문가와 개발자 사이의 가교

전력 소프트웨어 개발은 전력 계통 공학자, 정책 및 기준 수립자, 그리고 소프트웨어 엔지니어 간의 정확한 소통이 핵심입니다. 저는 비전공(경영학)에서 시작하여 전력거래소 기준서, 전력 계통 용어, 복잡한 수학적 수식을 코드로 구체화하는 과정에서 전문가들의 요구사항을 경청하고 명확한 데이터 규격과 API 명세서로 문서화하는 협업 방식을 체화했습니다.

에코아이티에서는 수동 검수의 비효율을 줄이고자 스스로 10가지 검증 룰 기반의 자동화 검수 플랫폼을 제작해 동료들의 작업 시간을 획기적으로 단축하기도 했습니다.

KEPCO에서도 타 부서 및 계통 현장과의 긴밀한 소통을 통해 사용자가 신뢰할 수 있는 최적의 ICT 솔루션을 만들어 가겠습니다.
