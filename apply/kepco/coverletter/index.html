01.한전 연구직 채용에 지원하게 된 동기804 / 1000자

[전력 데이터 실무와 AI 학습 데이터 품질 관리 경험을 잇는 지원]

약 3년간 민간 가상발전소(VPP) 플랫폼과 전력거래소 기준서 기반 고객기준부하(CBL) 계산 시스템을 개발·운영하며 전력 도메인 데이터를 다뤘습니다. 이후 단기 계약으로 국회 AI 학습 데이터 구축 사업에 참여해 전문 텍스트 데이터의 품질 검수를 담당했고, 현재는 차세대그리드 연구소에서 전력망 연구 플랫폼의 웹 운영과 소프트웨어 유지보수를 맡고 있습니다.

AI 데이터 구축 현장에서 가장 크게 느낀 점은, 모델의 성능은 결국 학습 데이터의 일관성에서 갈린다는 사실이었습니다. 입법례와 정책 문서를 가공할 때 작업자마다 기준이 다르면 데이터가 쉽게 흔들렸습니다. 기준을 통일하고 자동 검사 규칙을 만들어 시스템이 먼저 걸러내도록 한 뒤에야 검수자들이 문맥 판단에 집중할 수 있었습니다.

전력 산업 특화 언어 모델이나 AI 솔루션을 구축하려면, 전력 도메인의 문서와 계통 데이터를 정확히 읽어낼 수 있는 사람이 데이터를 정제해야 한다고 생각합니다. 전력거래소 기준서를 조문 단위로 분석해 알고리즘으로 구현해 본 경험과, 대규모 학습 데이터의 품질 기준을 세워 자동화해 본 경험이 이 직무에 부합한다고 판단했습니다.

무엇보다 전력 특화 AI는 실제 계통·설비·수요 데이터를 보유한 한전에서만 제대로 연구하고 발전시킬 수 있습니다. 그동안 프로젝트 단위 계약으로 참여하며 도메인 데이터를 장기적으로 축적하지 못했던 아쉬움을 딛고, 한전의 풍부한 데이터 자산을 바탕으로 모델이 학습할 수 있는 데이터를 만들고 이를 현업이 활용하는 플랫폼까지 연결하고자 지원했습니다.

02.지원직무와 관련된 지식 및 보유 Skill, 연구실적, 경력, 경험 등 (사용 Tool 포함)1857 / 2000자

[AI 학습 데이터 구축 및 품질 검수 자동화] 국회 입법 분야 AI 학습 데이터 구축 사업에서 외국 입법례와 정책 분석 자료 등 전문 텍스트의 최종 품질 검수를 담당했습니다. 검수자 간 기준 편차를 줄이기 위해 검수 표준 가이드와 업무 FAQ를 작성해 배포했고, 수작업 대조의 한계를 극복하기 위해 검수 웹 플랫폼을 직접 개발했습니다. 스키마 유효성, 필드 간 논리 모순, 필수 메타데이터 누락 등을 판별하는 10가지 자동 검증 규칙과 대용량 ZIP 파일 파싱 기능, 실시간 품질 통계 대시보드를 구현했습니다(React, TypeScript, FastAPI, Supabase, Docker). 이를 통해 단순 포맷 오류를 100% 걸러내고 검수 인력이 문맥 검증에만 집중할 수 있도록 했습니다.

[전력 도메인 시계열 데이터 처리] 전력거래소 기준서에 명시된 CBL 알고리즘 7종(MAX_4_5, MID_4_6, JP_STANDARD_BL 등)을 한국과 일본 시장 규정에 맞춰 Python 코드로 구현하고, 수요반응 성과 지표(RRMSE)를 산출했습니다. 15분·30분·60분 주기의 대용량 시계열 전력 데이터는 KDB+ 시계열 데이터베이스의 Q 언어로 조회·가공했으며, 이상치를 분석해 계산 결과의 신뢰도를 관리했습니다. 전력 도메인 규칙과 대용량 데이터 처리 흐름을 함께 익힌 실무 경험입니다.

[빅데이터 수집 및 시각화 플랫폼 구축] 분산 에너지 자원의 시계열 데이터를 분석하고 시각화하는 플랫폼(D3) 개발에 기획 단계부터 참여했습니다. API, S3 등 여러 소스에서 1분 주기로 데이터를 수집하는 파이프라인을 만들고, PostgreSQL 스키마 설계와 30여 개 REST API 개발, Highcharts 다중 시리즈 차트와 대시보드 UI를 구축하여 현업 실무자가 필요한 통계를 직접 조회·분석할 수 있도록 지원했습니다.

[최신 AI 모델 연동 및 서비스 개발] 개인 프로젝트로 Google Gemini 대규모 언어 모델 API를 연동한 정보 관리 웹 서비스를 개발해 운영하고 있습니다. 수집된 문서를 자동으로 카테고리 분류, 요약, 태그 추출하도록 파이프라인을 구성했고, API 호출 시 발생하는 Rate Limit 대응과 데이터 백필 처리 로직을 안정화했습니다. Next.js와 Supabase 기반으로 개발하고 46개 단위 테스트로 품질을 검증했습니다.

[백엔드 성능 최적화 및 인프라 자동화] 동기식 Flask API 서버에서 KDB+ 시계열 쿼리나 최적화 스케줄링 연산 시 발생하던 블로킹 문제를 진단하고, Uvicorn 기반 FastAPI 비동기 서버로 전환했습니다. 부하가 큰 연산은 Gevent 분산 태스크 워커 8개로 분리해 처리 지연을 해소했습니다. 또한 Docker 컨테이너화와 GitHub Actions CI/CD 파이프라인을 구축해 개발·운영 환경 분리와 무중단 배포를 체계화했습니다.

[현재 수행 업무] 차세대그리드 연구소에서 연구 플랫폼의 웹 시스템 운영과 소프트웨어 유지보수를 담당하며, 연구진이 다루는 전력망 데이터가 화면에 정확히 표시되도록 인터페이스를 개선하고 플랫폼 인프라를 관리하고 있습니다.

[보유 Skill 및 사용 Tool] 언어·백엔드: Python(FastAPI, Flask), Spring Boot, TypeScript / 데이터·분석: PostgreSQL, KDB+, Pandas, Scikit-learn, PuLP, Pyomo / AI: Google Gemini API 연동, 학습 데이터 품질 검증 자동화 / 프론트엔드: React, Next.js, Vue.js, Highcharts / 인프라: Docker, GitHub Actions CI/CD, AWS(EC2, Elastic Beanstalk, S3, Lightsail), Vercel.

03.입사 후 목표663 / 1000자

[전력 데이터를 모델이 학습할 수 있는 정제된 자산으로 구축]

입사 후에는 먼저 한전이 축적해 온 전력 데이터의 구조와 현업의 업무 규칙을 파악하는 데 집중하겠습니다. 어떤 데이터가 어디서 수집되고 어떤 규정에 따라 해석되는지 실무자들과 소통하며 빠르게 익히겠습니다. 전력거래소 기준서를 조문 단위로 분석해 코드로 구현했던 경험을 살려, 도메인 언어를 정확히 이해한 뒤 시스템에 접근하겠습니다.

이어서 전력 계통 및 설비 데이터를 AI 모델이 학습할 수 있는 고품질 데이터셋으로 가공하는 업무를 맡고 싶습니다. 전력 산업 특화 AI의 품질은 설비 이력, 규정 문서, 계통 운영 기록이 얼마나 일관되게 정제되어 있는지에 달려 있습니다. 학습 데이터의 검증 기준을 세우고 자동 검증 체계를 만들어 데이터의 무결성을 확보하는 일은, AI 데이터 구축 현장에서 제가 직접 성공적으로 수행했던 작업입니다.

장기적으로는 완성된 모델이 현업의 의사결정으로 이어질 수 있도록 안정적인 서비스 플랫폼을 구축하겠습니다. 모델 결과가 아무리 우수해도 담당자가 손쉽게 조회하고 검증할 수 있는 인터페이스가 없으면 실무에 안착하기 어렵습니다. 데이터 수집과 정제, 모델 학습, 결과 조회가 유기적으로 연결되는 웹 플랫폼을 구축하여, 현업 부서가 신뢰하고 활용할 수 있는 전력 AI 환경을 완성하겠습니다.
