홈입사지원서경력기술서

Korea Electric Power Corporation · ICT

자 기 소 개 서

지원자: 김제민 (KIM JE MIN)

01.지원 동기 및 직무 비전 — 전력망 지능화와 데이터 신뢰성 확보

아이온커뮤니케이션즈와 이아이피그리드에서 약 3년간 민간 가상발전소(VPP) 플랫폼과 전력거래소 기준 수요반응(DR) 고객기준부하(CBL) 계산 시스템을 개발·운영했습니다. 현재는 한국에너지공과대학교(KENTECH) AGM Center에서 차세대 전력망 운영 소프트웨어(KPG)의 Python 연산 로직 개선과 웹 플랫폼 유지보수를 맡고 있습니다.

신재생에너지 분산 전원이 빠르게 늘어나면서 국내 전력 계통의 변동성과 복잡도는 그 어느 때보다 높아졌습니다. 한국전력공사의 ICT 시스템은 단순한 전산 관리를 넘어, 전력망의 안전과 수급 균형을 실시간 데이터로 지탱하는 두뇌 역할을 해야 합니다.

민간 VPP 시장과 연구소 전력망 소프트웨어를 거치며 쌓은 전력 도메인 이해도와 대용량 시계열 데이터 처리 경험을 살려, 한국전력공사의 차세대 전력 ICT 시스템 구축과 지능형 데이터 운영에 기여하고자 지원했습니다.

02.직무 전문성 — 전력 시계열 데이터 파이프라인과 연산 최적화

전력거래소 기준서에 명시된 CBL 알고리즘 7종을 Python으로 구현하고, 스마트미터에서 수집되는 대규모 시계열 전력 데이터를 KDB+ 데이터베이스로 정제·조회하는 파이프라인을 설계했습니다.

에너지저장장치(ESS)의 피크 부하 감축과 충·방전 스케줄링을 위해 선형 프로그래밍(PuLP/Pyomo) 최적화 모델을 코드로 작성하여 경제적인 운용 알고리즘을 개발했습니다.

KENTECH 연구소에서는 전력망 조류 해석 소프트웨어인 KPG Run/View의 핵심 Python 로직을 분석하고 연산 병목을 개선하며 계통 해석 도구의 실무 메커니즘을 익혔습니다. 이러한 실무 경험은 한전이 다루는 방대한 SCADA/EMS 및 AMI 계통 데이터의 실시간 모니터링과 분석 체계를 고도화하는 데 즉시 활용될 수 있습니다.

03.문제 해결 역량 — 비동기 아키텍처 전환으로 동시 처리 병목 해소

D1 프로젝트 운영 당시, 기존 Flask 동기식 API 구조에서는 여러 사업자의 대용량 CBL 계산 요청이 동시에 들어올 때 서버 응답이 지연되고 요청이 밀리는 문제가 있었습니다. 이를 해결하기 위해 Uvicorn ASGI 기반의 FastAPI로 시스템을 마이그레이션했습니다.

SQLAlchemy 2.0 비동기 세션을 적용하고 Gevent 기반 8개 분산 태스크 워커를 두어 I/O 대기 시간을 해소했습니다. 그 결과 동시 대량 요청이 집중되는 상황에서도 응답 지연을 낮추고 계산 처리량을 크게 끌어올렸습니다.

기존 코드의 병목을 진단하고 최신 비동기 아키텍처로 안전하게 전환한 경험은, 한전의 대규모 ICT 시스템을 안정적이고 탄력적으로 운영하는 밑바탕이 될 것입니다.

04.협업과 소통 — 도메인 전문가와의 긴밀한 조율과 업무 자동화

전력 소프트웨어 개발은 계통 공학자, 정책 기준 수립자, 개발자 간의 정확한 소통이 필수적입니다. 비전공(경영학)으로 시작했기에 전력거래소 기준서와 복잡한 계통 수식을 코드로 옮기는 과정에서 도메인 전문가의 요구사항을 세심히 듣고, 명확한 데이터 규격과 API 명세서로 정리해 소통하는 방식을 체득했습니다.

에코아이티에서는 수작업 검수의 혼선을 줄이고자 10가지 자동 검증 규칙을 갖춘 검수 웹 플랫폼을 직접 만들어 동료들의 작업 시간을 획기적으로 줄였습니다.

한전에서도 현장 부서 및 도메인 전문가들과 긴밀히 소통하며, 사용자가 믿고 쓸 수 있는 전력 ICT 솔루션을 만들어 가겠습니다.
